# Formats

V1 focuses on LinkedIn posts. Format guidance is lightweight support for the Content Agent, not a standalone workflow.

## Text Post

Use for:

- Founder POV
- Buyer belief shifts
- Operator lessons
- Market signal reactions
- Practical short frameworks

Guidelines:

- Strong first 210 characters.
- Short lines.
- One idea.
- Clear belief shift.
- CTA only when useful.

## Carousel Or Document Post

Use only when the idea needs multiple steps, a framework, or a visual breakdown.

Guidelines:

- One idea per slide.
- Cover slide acts as a second hook.
- Final slide can include a simple CTA.
- Do not turn every post into a carousel.

## Visual Companion

Use when a simple graphic would make the buyer understand the idea faster.

Good fits:

- Before/after comparison
- Operating model
- Decision tree
- Framework
- Mistake map

## Avoid

- Choosing formats based only on generic reach.
- Adding visuals that do not clarify the buyer problem.
- Polls, newsletters, Lives, audio events, or repurposing workflows in v1.
